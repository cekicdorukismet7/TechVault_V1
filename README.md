## Key Features & Software Architecture

- **Device Registration:** Add technical equipment by entering its name, brand, and model.
- **Unique Inventory IDs:** Automatically generate identifiers such as `TV-001`, `TV-002`, and more.
- **Inventory Listing:** Display registered devices and their details in a structured format.
- **Interactive CLI:** Navigate the application through a simple command-line menu.
- **Modular Development:** Build and improve the system incrementally as new features are implemented.

## Core Features

- Add new devices to the inventory.
- View all registered devices.
- Generate sequential inventory IDs automatically.
- Handle invalid menu choices.

## Tech Stack

- **Language:** Python 3
- **Data Structures:** Lists and dictionaries
- **Version Control:** Git and GitHub

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open a terminal in the project directory.
4. Run the application:

```bash
python main.py
```

## Current Limitations

- Device records are stored in memory and are lost when the application closes.
- Device deletion by inventory ID is still under development.
- A database has not yet been integrated.
